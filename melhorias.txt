
Lista de Melhorias
Arquitetura & Qualidade
Zero cobertura de testes — nenhum arquivo de teste no projeto. DAOs e repositórios são os candidatos mais críticos; falhas de schema ou migration quebram silenciosamente.

src/renderer/lib/media.ts não existe — estava no mapa mental do projeto mas o arquivo real é utils/media.ts. Verificar se há imports quebrados apontando para o caminho errado.

Botão de filtro avançado não implementado — SearchInput.tsx tem um botão visível na UI que não faz nada. Implementar ou remover.

Migração de localStorage em appStatePersistence.ts — código de migração legacy ainda presente. Se todos os usuários já migraram, pode ser removido com segurança.

Robustez
Threshold de matching de ROM hardcoded (0.72) — número mágico em romFolderImport.ts. Expor como constante nomeada ou configuração do usuário.

dataPortability.ts tem CRC32 e ZIP64 manual — implementação custom de algoritmos ZIP ao lado do adm-zip. Indica que o adm-zip não suportou ZIP64; documentar a limitação ou trocar de biblioteca.

Workaround de capitalização de path no Windows — appPaths.ts tem lógica de normalização de capitalização específica para Windows. Frágil; substituir por fs.realpath() ou equivalente.

Sem ErrorBoundary no React — qualquer exceção não tratada em componente derruba toda a UI sem mensagem de erro legível.

Performance
Cache de LaunchBox apenas em memória + disco — invalidação do índice usa condição única; múltiplos downloads simultâneos podem corromper o cache. Adicionar lock ou fila.

PAGE_SIZE fixo em Pagination.tsx — tamanho de página não configurável pelo usuário; coleções grandes com covers pesadas ficam lentas.

UX & Features
Catálogo de plataformas estático — platformCatalog.ts é lista hardcoded. Usuários com plataformas customizadas não conseguem adicionar entradas sem editar código.

Sem tela de carregamento na hidratação inicial — App.tsx hidrata do SQLite na abertura; se o banco for grande, a janela aparece em branco por instantes (parcialmente mitigado pelo "defer show", mas sem feedback visual).

Sem internacionalização (i18n) — strings de UI misturadas entre pt-br e en nos componentes. Se o app crescer para outros idiomas, refatorar será custoso.

Prioridade de região de imagem hardcoded no LaunchBox — scraper.ts tem ordem de preferência de região (ex: United States antes de Europe) fixada no código; deveria ser configuração do usuário.

Sem paginação na lista de emuladores/plataformas — EmulatorsSettings e PlatformManager carregam tudo de uma vez; com muitas entradas, a UI fica pesada.

Segurança
Paths de ROM não são sanitizados antes de passar ao shell.openPath — verificar se há validação de caminho em index.ts antes de abrir arquivos externos; path traversal é possível via IPC se o renderer for comprometido.
